# Brokoliny Bot

Telegram-бот на aiogram 3 для игровых домашних занятий с модульной AI-маршрутизацией,
PDF-распечатками и защищённой админ-панелью.

## Архитектура

- `app/ai.py` — единый model-agnostic сервис: отдельные маршруты диагностики,
  ежедневных планов и изображений; текстовые запросы используют JSON Schema и
  Pydantic-валидацию ответа.
- `app/database.py` — SQLite-профили, наблюдения навыков, планы, кэш изображений,
  общая библиотека вопросов/заданий/игр, персональная история использованного
  контента, настройки, версии промтов и учёт расходов.
- `app/content_library.py` — выдача ранее сгенерированных уникальных компонентов
  и генерация только при нехватке неиспользованных элементов для пользователя.
- `app/bot.py` — FSM-онбординг, игровые наблюдения, открытый финальный вопрос,
  обратная связь по сложности и настройка времени доставки.
- `app/printables.py` — детерминированная векторная сборка PDF A4 и PNG-стимулов.
- `app/scheduler.py` — ежедневная рассылка с APScheduler; ранее сохранённый план
  со статусом `pending` доставляется, а не генерируется заново.
- `app/admin.py` + `admin.html` — FastAPI-панель: пользователи, профили, планы,
  маршруты, версии промтов, лимиты, зашифрованные API-ключи и кэш изображений.
  Стиль генерации изображений редактируется вместе с системными промтами и
  применяется при следующем запросе без перезапуска.

## Запуск на macOS

Нужен Python 3.11 или новее. Откройте `start.command` двойным щелчком. При первом
запуске файл подготовит виртуальное окружение и установит зависимости, затем
попросит токен Telegram, ключ Gemini и пароль админ-панели. Ввод скрыт. Ключ
шифрования создаётся автоматически и сохраняется в `.env`; остальные параметры
по умолчанию берутся из `.env.example`.

После запуска откроется `http://127.0.0.1:8000/admin`. Введите пароль админ-панели,
который указали при первом запуске. Не закрывайте окно Терминала: `Ctrl+C`
остановит и бота, и админку. Запускайте `start.command` снова, чтобы поднять их
позже; уже заполненные поля можно оставить пустыми нажатием Enter.

Файл `.env` содержит секреты и исключён из Git. Сделайте резервную копию
`DATA_ENCRYPTION_KEY` отдельно: без неё сохранённые зашифрованные заметки и ключи
провайдеров невозможно восстановить. Для Vertex AI настройте стандартные
Application Default Credentials.

В панели меняются модели каждой задачи без перезапуска: например, для диагностики
укажите `anthropic` / `claude-3-7-sonnet` или `openai` / `o3-mini`; для изображений
укажите `openai` / `dall-e-3` либо `replicate` / `black-forest-labs/flux-1.1-pro`.
Соответствующий ключ можно задать в окружении или сохранить зашифрованно в панели.

Панель находится по адресу `http://127.0.0.1:8000/admin`. API панели требует
`Authorization: Bearer <ADMIN_TOKEN>`. Не публикуйте сервис без HTTPS и защиты
сетевого уровня. Для локального запуска привязка к loopback ограничивает доступ
этим компьютером.

В списке пользователей кнопка «Удалить пользователя» удаляет локальный профиль,
наблюдения навыков, планы, оценки и историю выданного контента; общий кэш
контента сохраняется. Текст сообщений в Telegram бот не архивирует и эта кнопка
не удаляет сообщения из самого Telegram.
В истории планов у каждого ранее отправленного дня есть действие повторной
отправки сохранённого плана. Оно не запускает AI-генерацию и не меняет отметку о
первой доставке. Пользователь также может в личном чате отправить `/resend`,
чтобы повторно получить уже отправленный план за сегодня; команда не запускает
генерацию нового плана. Команда `/reganaratdayplan` в личном чате создаёт план
на сегодня, если его ещё нет, либо заменяет существующий; она может расходовать
токены, а если генерация не удалась, старый план сохраняется. Имя и фамилию
пользователя, имя ребёнка и (по желанию) телефон бот запрашивает
только после отдельного согласия; отказ не мешает пользоваться ботом. Данные
хранятся зашифрованно, не передаются AI и доступны администратору только после
согласия. Команда `/identity` позволяет изменить согласие или отозвать его.

Задайте `FONT_PATH` в `.env`, если шрифт не найден автоматически. `TIMEZONE`
управляет ежедневным расписанием.

## Приватность и границы применения

Заметки о здоровье/особенностях ребёнка шифруются в SQLite. Перед отправкой такой
заметки AI-провайдеру бот отдельно запрашивает согласие; отказ не мешает пройти
игровые задания. Обычные данные профиля и планы хранятся в SQLite без шифрования
всей базы, поэтому ограничьте доступ к файлу базы и резервным копиям. Контактные
данные, если пользователь отдельно разрешил их сбор, шифруются тем же ключом и
передаются только защищённой админ-панели. Дата рождения ребёнка также хранится
зашифрованной и в AI-запрос передаётся только вычисленный возраст в месяцах.

Бот не проводит медицинскую диагностику, не выставляет оценки DDST-II и не
воспроизводит стандартизированные тестовые задания. Упоминание Выготского и
общедоступных ориентиров ВОЗ используется только как общий образовательный
контекст, а не как доказательство нормы или отклонения. При беспокойстве о
развитии следует обратиться к квалифицированному специалисту.

AI-ответы валидируются по JSON Schema. Ошибка провайдера не заменяется
выдуманным структурированным ответом. Распечатки с геометрией генерируются
векторно, без зависимости от точности AI-рисунка. Сюжетная иллюстрация
генерируется только если план содержит `story_prompt`; после отправки Telegram
`file_id` повторно используется из кэша.

Вопросы кэшируются для возрастной группы, а игры/задания/советы — для возрастной
группы, наблюдаемых областей навыков и оценки сложности. Пул общий, но перед
выдачей компоненты атомарно резервируются в персональной истории; точное или
похожее ранее выданное содержимое повторно не используется. Если не хватает
нового элемента — бот делает AI-запрос, наполняет пул и выбирает неиспользованное.
В начале `/start` пользователь выбирает русский или украинский язык; выбор
сохраняется в профиле и учитывается при генерации и выдаче следующих заданий.
В онбординге вводится дата рождения, а возраст в завершённых месяцах
пересчитывается для диагностики и каждого нового плана. Кэш игр и заданий
разделён по точному возрасту в месяцах. Дата рождения хранится зашифрованно;
пользователям со старым профилем без даты нужно пройти `/start` и указать её.
Стимульная картинка для диагностического вопроса необязательна, а сюжетная
иллюстрация для плана создаётся только по необходимости. Векторная PDF-распечатка
фокусного задания остаётся частью ежедневного плана.
После первого завершения регистрации бот сразу отправляет план на сегодня;
плановая рассылка начинается со следующего дня в выбранное время.
Раздаточные PNG отличаются вариацией макета; изображения сверяются по SHA-256 и
перцептивному dHash, чтобы отсеять точные копии и визуально близкие варианты.
Если после ограниченных попыток нельзя получить новую картинку/задание, бот откажет в
повторной выдаче и запишет ошибку, а не отправит старое.

Админка показывает кэш заданий для выбранного пользователя по
`/admin/content-cache?telegram_id=<ID>` и позволяет удалять элементы общего пула.

Дневной бюджет останавливает новые запросы после достижения записанной
LiteLLM-стоимости; если провайдер не возвращает стоимость, точный финансовый
лимит обеспечить нельзя. Лимит токенов применяется к каждому текстовому запросу.
